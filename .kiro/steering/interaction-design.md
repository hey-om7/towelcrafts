# Interaction Design System

Interactions must feel intentional, subtle and premium.

## Buttons

Every primary button should have:

- clear default state
- hover state
- active state
- focus state
- disabled state
- loading state where relevant

Avoid exaggerated scale animations.

Prefer subtle:
- translation
- opacity
- background transitions
- underline movement
- icon movement

## Links

Navigation links may use:
- underline reveal
- opacity transition
- subtle color transition

Avoid generic bounce animations.

## Images

Where appropriate, images may:
- subtly scale on hover
- reveal through clipping
- shift position slightly

Do not use large scale transforms that feel cheap.

## Scroll animation

Animations should support:
- hierarchy
- storytelling
- continuity

Avoid animating every element independently.

## Reduced motion

Respect prefers-reduced-motion.

When reduced motion is enabled:
- remove parallax
- reduce transforms
- remove decorative motion
- preserve functional transitions
