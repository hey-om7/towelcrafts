# Visual Design System

The website must feel professionally art-directed, premium, modern and visually
distinctive. Do NOT default to generic AI/SaaS website patterns.

## Core principles

1. Composition before components.
2. Typography is a primary visual element.
3. Photography, illustration, 3D and other visual assets should be treated as
   first-class design elements.
4. Avoid repetitive card grids.
5. Avoid excessive rounded containers.
6. Avoid gratuitous gradients.
7. Avoid generic "hero + 3 cards + testimonials + CTA" layouts unless the
   product genuinely requires them.
8. Use intentional asymmetry where appropriate.
9. Use strong visual hierarchy.
10. Every section should have a distinct purpose and visual composition.

## Imagery

Use high-resolution, professional visual assets.

Do not use:
- blurry imagery
- low-resolution placeholder images
- generic stock-photo aesthetics
- random Unsplash images with no art direction
- placeholder gray boxes in the finished UI

When an image is required, determine:
- subject
- composition
- aspect ratio
- crop
- focal point
- lighting
- color treatment
- relationship to surrounding typography

Images should normally be prepared in appropriate WebP/AVIF sizes.

## Typography

Typography should create hierarchy and personality.

Use:
- expressive display typography for major headlines
- readable text typography
- intentional tracking
- strong scale contrast
- restrained font weights

Do not make every heading look like a standard Tailwind heading.

## Layout

Favor:
- editorial compositions
- asymmetric grids
- oversized typography
- layered imagery
- controlled negative space
- full-bleed visual sections
- overlapping elements where appropriate
- intentional vertical rhythm

Avoid:
- endless centered containers
- identical cards
- predictable three-column layouts
- excessive borders
- excessive shadows

## Motion

Use subtle, purposeful motion:
- entrance transitions
- image reveal
- parallax where appropriate
- hover states
- scroll-linked transitions

Motion must support hierarchy rather than distract.

## Quality bar

Before considering a page finished, inspect it as a designer.

Ask:

- Does this look like a template?
- Does this look AI-generated?
- Are the images genuinely high quality?
- Is there enough visual variety?
- Is the typography interesting?
- Does the page have a memorable composition?
- Are the sections visually differentiated?
- Would this look credible on a professional agency portfolio?
